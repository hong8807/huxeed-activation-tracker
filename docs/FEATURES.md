## 📊 Dashboard (대시보드)

### KPI 카드 (4개)
- **평균 진척률(%)**: 전체 품목의 평균 진행률
- **완료(WON) 건수**: WON 단계 품목 개수
- **Target매출액**: 모든 품목의 예상매출액 합계 (백만원)
- **전략달성율(%)**: (WON 품목 매출 / Target매출액) × 100

### 전략 카드
- **White Space 전략**: S세그먼트 품목 현황
- **Erdosteine 전략**: P세그먼트 품목 현황
- 세그먼트별 진행률, 매출액 표시

### 차트
- 단계별 진행 퍼널 (12단계)
- 거래처별 진행률 막대그래프

---

## 🎯 Pipeline (파이프라인)

### 12단계 칸반보드

| 순서 | 단계 | 진행률 |
|------|------|--------|
| 1 | 시장조사 (MARKET_RESEARCH) | 0% |
| 2 | 소싱요청 (SOURCING_REQUEST) | 5% |
| 3 | 소싱완료 (SOURCING_COMPLETED) | 10% |
| 4 | 견적발송 (QUOTE_SENT) | 20% |
| 5 | 샘플배송 (SAMPLE_SHIPPED) | 30% |
| 6 | 품질테스트 (QUALIFICATION) | 40% |
| 7 | DMF/RA검토 (DMF_RA_REVIEW) | 50% |
| 8 | 가격합의 (PRICE_AGREED) | 60% |
| 9 | 시험PO (TRIAL_PO) | 70% |
| 10 | 완제연계심사중 (REGISTRATION) | 80% |
| 11 | 상업PO (COMMERCIAL_PO) | 90% |
| 12 | 완료 (WON) | 100% |
| - | 실패 (LOST) | 0% |
| - | 보류 (ON_HOLD) | 50% |

### 기능
- ✅ 드래그앤드롭으로 단계 이동
- ✅ 단계 이동 시 날짜/이력 자동 기록
- ✅ 제조원 없으면 소싱요청 이후 이동 불가
- ✅ 카드 삭제 기능 (CASCADE 삭제)
- ✅ 상세 모달 (가격 비교, 절감 분석, 이력)

### 신규 품목 등록 (`/pipeline/add`)
- ✅ 22개 필드 입력 폼
- ✅ 통화 선택 (USD, EUR, CNY, JPY, KRW)
- ✅ 환율 자동 조회 (한국수출입은행 API)
- ✅ 자동 계산 (KRW 환산, 절감 지표)
- ✅ 거래처명/품목명 자동완성
